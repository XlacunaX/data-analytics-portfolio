# Machine Learning Project

This project was completed as part of the **Machine Learning course** in the **Master of Analytics program at RMIT University**.

## Objective
Apply machine learning techniques to analyse data and build predictive models.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- Scikit-learn
- Matplotlib / Seaborn

## Methods
The project includes:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training
- Model evaluation
