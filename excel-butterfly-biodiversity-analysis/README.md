# Butterfly Biodiversity Analysis – Excel Data Analysis

This project was completed as part of the **Applied Analytics course** in the **Master of Analytics program at RMIT University**.

## Objective
Analyse butterfly biodiversity and flower–butterfly interactions in Melbourne using Excel data analysis techniques.

## Dataset
The dataset contains **146,012 observations** of butterfly sightings and plant interactions collected across multiple sites in Melbourne. :contentReference[oaicite:0]{index=0}

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Functions

## Analysis Performed

The analysis included:

- Comparing relative humidity across locations within the Royal Park site
- Identifying the plant families with the highest number of *Pieris rapae* butterflies
- Calculating walk time conditions using Excel formulas
- Analysing average temperature trends across months
- Identifying biodiversity hotspots for butterfly species

## Key Insights

- Royal Park and Women's Peace Garden recorded the highest butterfly sightings.
- Certain plant species attracted significantly more butterfly interactions.
- Seasonal temperature variations influenced butterfly activity patterns.
