# Regression Analysis – Air Quality & Electricity Consumption

This project was completed as part of the **Regression Analysis course (MATH1312)** in the **Master of Analytics program at RMIT University**.

## Objective
Investigate relationships between variables using linear regression models and statistical inference techniques.

## Datasets

Two datasets were analysed:

1. **Factories vs Air Quality Index (AQI)**  
   Examining how the number of factories affects air quality.

2. **Electricity Consumption vs Temperature**  
   Investigating how outdoor temperature influences household electricity usage.

## Tools Used
- R
- RStudio
- ggplot2
- Excel (for manual calculations)

## Methods

The following statistical techniques were applied:

- Scatterplot analysis
- Simple Linear Regression
- Least Squares estimation
- ANOVA testing
- Residual analysis
- Hypothesis testing
- Confidence intervals
- Correlation analysis

## Key Insights

- A **positive linear relationship** was found between number of factories and AQI, suggesting industrial activity worsens air quality.
- A **strong negative relationship** was found between electricity consumption and temperature.

- Residual diagnostics confirmed that regression assumptions were satisfied.
