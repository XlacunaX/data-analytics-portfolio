# Data Cleaning and Exploration Using Python

This project was completed as part of the **Practical Data Science (with Python)** course in the **Master of Analytics program at RMIT University**.

## Objective
Perform data preparation and exploratory analysis on a dataset describing internet connectivity among school-age children across different countries.

## Dataset
The dataset contains global information about the **percentage of school-age children with internet access at home**, categorized by:

- Region
- Residence (Urban vs Rural)
- Wealth quintile (Poorest vs Richest)

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Methods

The following data science steps were implemented:

### Data Preparation
- Data type conversion (percentage strings → numeric values)
- Handling missing values
- Outlier detection and removal
- Duplicate row removal

### Data Exploration
Analysis included:

- Boxplot visualization of internet access by region
- Median internet connectivity comparisons
- Wealth quintile analysis (Poorest vs Richest)
- Rural vs Urban connectivity comparison using:
  - Mean
  - Median
  - Standard deviation

## Key Insights

- Eastern Europe and Central Asia showed the highest internet connectivity.
- Sub-Saharan Africa had the lowest connectivity.
- Internet access in **urban areas is more than double rural areas**.
- Wealth inequality significantly affects internet connectivity.
